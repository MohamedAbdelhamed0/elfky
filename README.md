## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **i18n**: next-intl (Bilingual Arabic/English with full RTL support)
- **Styling**: Vanilla CSS + CSS Modules + Modern Glassmorphism Design System
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Hosting**: GitHub Pages via GitHub Actions
